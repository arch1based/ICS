# ICS Store Signage — Προβολή προσφορών σε οθόνη καταστήματος

Παίζει **εικόνες και βίντεο** σε **πλήρη οθόνη** με **εφέ μετάβασης** (fade, slide, zoom, flip, blur ή τυχαίο),
με **πρόγραμμα ανά ημέρα της εβδομάδας** (και προαιρετικά ημερομηνίες Από/Έως).

## Εγκατάσταση (Windows, μία φορά)
1. Εγκατάσταση **Python 3.9+** από https://www.python.org (τσεκάρετε *Add Python to PATH*).
2. Αντιγραφή του φακέλου `store-signage` π.χ. στο `C:\ICS-Signage`.
3. Για αυτόματη εκκίνηση: `Win+R` → `shell:startup` → δημιουργία συντόμευσης του `start.bat`.

## Φάκελοι
```
media\
  Προσφορές Εβδομάδας\
     Δευτέρα-Τετάρτη\    ← εικόνες / βίντεο
     Πέμπτη-Κυριακή\
  Προσφορές Ημέρας\
     Παράδειγμα\
```
- Κάθε **υποφάκελος = μία καμπάνια** (ονομάστε τους όπως θέλετε, φτιάξτε όσους θέλετε).
- Σειρά προβολής: πρώτα όλες οι ενεργές **της εβδομάδας**, μετά **έξτρα** οι ενεργές **της ημέρας**, και ξανά από την αρχή.
- Τα αρχεία παίζουν αλφαβητικά (βάλτε `01_`, `02_`… για δική σας σειρά).
- Υποστηρίζονται: `jpg png gif webp bmp` και `mp4 webm` (προτείνεται MP4/H.264).
- Νέα/διαγραμμένα αρχεία εφαρμόζονται αυτόματα στον επόμενο κύκλο — χωρίς επανεκκίνηση.

## Χρήση
| Αρχείο | Τι κάνει |
|---|---|
| `start.bat` | Ξεκινά την προβολή σε πλήρη οθόνη (Edge/Chrome kiosk) |
| `admin.bat` | Ανοίγει τη σελίδα ρυθμίσεων (ημέρες, ημερομηνίες, εφέ, διάρκεια εικόνας, ήχος) |
| `stop.bat`  | Κλείνει την προβολή και τον server |

Στη σελίδα ρυθμίσεων επιλέγετε για κάθε καμπάνια τις ημέρες (π.χ. **Δε–Τε** τη μία, **Πε–Κυ** την άλλη) και πατάτε **Αποθήκευση**.
Η στήλη «Σήμερα» δείχνει τι παίζει σήμερα. Στην αλλαγή ημέρας η λίστα ανανεώνεται μόνη της.

Πλήκτρα στην προβολή: `F2` ρυθμίσεις, `→` επόμενο, `Alt+F4` έξοδος.

Οι ρυθμίσεις αποθηκεύονται στο `schedule.json`. Ο server ακούει μόνο τοπικά (`127.0.0.1:8765`).
