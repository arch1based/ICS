# ITNow Signage — Προβολή προσφορών σε οθόνη καταστήματος

*από την [itnow.gr](https://itnow.gr)*

Παίζει **εικόνες και βίντεο** σε **πλήρη οθόνη** με **εφέ μετάβασης** (fade, slide, zoom, flip, blur ή τυχαίο),
με **πρόγραμμα ανά ημέρα της εβδομάδας** (και προαιρετικά ημερομηνίες Από/Έως).

## Εγκατάσταση (Windows 10/11)
1. Κατεβάστε το **`ITNow-Signage.exe`** (Releases του repo) — δεν χρειάζεται Python ή άλλο πρόγραμμα.
2. Διπλό κλικ. Ρωτάει τι θα είναι ο υπολογιστής:
   - **ΝΑΙ = Κεντρικός**: εδώ μπαίνουν οι φάκελοι, εδώ ορίζονται μέρες/οθόνες. Ζητά μία φορά άδεια διαχειριστή (firewall) για να τον βλέπουν οι οθόνες.
   - **ΟΧΙ = Οθόνη**: βρίσκει **μόνη της** τον κεντρικό στο τοπικό δίκτυο και παίζει ό,τι ορίζει εκείνος.
3. Εγκαθίσταται στο **`C:\ITNow-Signage`**, φτιάχνει συντομεύσεις και ξεκινά αυτόματα με τα Windows.

> Αν εμφανιστεί το μπλε παράθυρο «Τα Windows προστάτευσαν τον υπολογιστή σας»: **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**.

## Κεντρικός & οθόνες
- Βάζετε όσες οθόνες θέλετε — όλες εμφανίζονται στον κεντρικό στην ενότητα **Οθόνες** (συνδεδεμένη / παίζει / εκτός σύνδεσης) με κουμπιά **Έναρξη / Διακοπή**.
- Σε κάθε φάκελο, εκτός από τις μέρες, διαλέγετε **σε ποιες οθόνες** παίζει («Όλες» ή συγκεκριμένες).
- Οι οθόνες κρατούν **τοπικό αντίγραφο** των αρχείων: αν κλείσει ο κεντρικός ή πέσει το δίκτυο, **συνεχίζουν να παίζουν**.
- Το όνομα κάθε οθόνης (π.χ. «Ταμείο 1») αλλάζει από το «ITNow Signage» της ίδιας της οθόνης.
  Αν δεν βρεθεί αυτόματα ο κεντρικός, γράψτε εκεί την IP του.
- Ο κεντρικός μπορεί να είναι και ο ίδιος οθόνη (φαίνεται πρώτος στη λίστα).
- Θύρες: TCP 8765 (σύνδεση) και UDP 8766 (αυτόματη εύρεση).

## Αυτόματη εκκίνηση & Demo
- Με το άνοιγμα των Windows ξεκινά **πάντα** ο server στο παρασκήνιο. Η προβολή ξεκινά πάντα στις οθόνες· στον κεντρικό μόνο αν την είχατε αφήσει να παίζει.
- Στην πρώτη εκκίνηση του κεντρικού δημιουργείται ο φάκελος **Προσφορές Εβδομάδας\Demo** με 5 εικόνες για έλεγχο των οθονών.

## Φάκελοι
```
C:\ITNow-Signage\
  Προσφορές Εβδομάδας\
     (δικοί σας υποφάκελοι, π.χ. «Γαλακτοκομικά»)   ← εικόνες / βίντεο
  Προσφορές Ημέρας\
     (δικοί σας υποφάκελοι)
```
- Κάθε **υποφάκελος = μία καμπάνια**. Τους φτιάχνετε με το **＋ Νέος φάκελος** στον Πίνακα Ελέγχου, με όποιο όνομα θέλετε.
- Σειρά προβολής: πρώτα όλες οι ενεργές **της εβδομάδας**, μετά **έξτρα** οι ενεργές **της ημέρας**, και ξανά από την αρχή.
- Τα αρχεία παίζουν αλφαβητικά (βάλτε `01_`, `02_`… για δική σας σειρά).
- Υποστηρίζονται: `jpg png gif webp bmp` και `mp4 webm` (προτείνεται MP4/H.264).
- Νέα/διαγραμμένα αρχεία εφαρμόζονται αυτόματα στον επόμενο κύκλο — χωρίς επανεκκίνηση.

## Χρήση — Πίνακας Ελέγχου
Ανοίγει από τη συντόμευση «ITNow Signage - Πίνακας Ελέγχου» σαν σύγχρονη εφαρμογή (ανοιχτό/σκούρο θέμα όπως τα Windows):
- **Έναρξη / Διακοπή προβολής** πάνω δεξιά, με ένδειξη αν παίζει τώρα.
- **Εβδομάδα με μια ματιά**: τι παίζει κάθε μέρα, με τη σημερινή να ξεχωρίζει.
- **Κάρτα για κάθε φάκελο** με μικρογραφίες των αρχείων, διακόπτη ενεργός/ανενεργός, **κουμπιά ημερών Δευ…Κυρ**,
  έτοιμες επιλογές (Όλες, Καθημερινές, Σαβ/κο, Δευ–Τετ, Πέμ–Κυρ) και προαιρετικά ημερομηνίες Από/Έως.
  Κλικ στις μικρογραφίες ανοίγει τον φάκελο για να ρίξετε εικόνες/βίντεο.
- **＋ Νέος φάκελος** σε κάθε ενότητα.
- Όλα **αποθηκεύονται αυτόματα** με το κλικ.

Κλείνοντας τον Πίνακα Ελέγχου η προβολή **συνεχίζει** κανονικά.

Πλήκτρα στην προβολή: `→` επόμενο, `Alt+F4` έξοδος.

Οι ρυθμίσεις αποθηκεύονται στο `schedule.json`. Ο server ακούει μόνο τοπικά (`127.0.0.1:8765`).

## Αναβαθμίσεις (μόνο τεχνικός)
**Προετοιμασία (μία φορά ανά νέα έκδοση)** — στο Google Drive:
1. Ανεβάστε το νέο `ITNow-Signage.exe` → Κοινή χρήση → **«Οποιοσδήποτε έχει τον σύνδεσμο»** → αντιγραφή συνδέσμου.
2. Επεξεργαστείτε το `version.json` (βγαίνει μαζί με το exe στα Releases) και βάλτε τον σύνδεσμο στο `"exe"`:
   ```json
   { "version": "1.0.1", "exe": "https://drive.google.com/file/d/XXXX/view", "notes": "Τι άλλαξε" }
   ```
3. Ανεβάστε το `version.json` στο Drive (πάντα **το ίδιο αρχείο** — «Διαχείριση εκδόσεων → Νέα έκδοση», ώστε να μην αλλάζει ο σύνδεσμος), επίσης δημόσιο.

**Στο κατάστημα:** Πίνακας Ελέγχου → κάτω κάτω **🔧 Τεχνικός** → κωδικός → επικόλληση συνδέσμου του `version.json` (μένει αποθηκευμένος)
→ **Έλεγχος** → **Αναβάθμιση**. Το πρόγραμμα κατεβάζει το νέο exe, το αντικαθιστά και ξεκινά ξανά μόνο του.
Οι φάκελοι, τα αρχεία και οι ρυθμίσεις ημερών **δεν επηρεάζονται**.
**Οι οθόνες αναβαθμίζονται αυτόματα** από τον κεντρικό μέσα σε λίγα δευτερόλεπτα — αρκεί να αναβαθμίσετε μόνο τον κεντρικό.
