# ITNow Signage — Προβολή προσφορών σε οθόνη καταστήματος

*από την [itnow.gr](https://itnow.gr)*

Παίζει **εικόνες και βίντεο** σε **πλήρη οθόνη** με **εφέ μετάβασης** (fade, slide, zoom, flip, blur ή τυχαίο),
με **πρόγραμμα ανά ημέρα της εβδομάδας** (και προαιρετικά ημερομηνίες Από/Έως).

## Εγκατάσταση (Windows, μία φορά)
1. Αντιγράψτε τον φάκελο `store-signage` στον υπολογιστή (π.χ. από USB).
2. Διπλό κλικ στο **`ΕΓΚΑΤΑΣΤΑΣΗ.bat`**. Αυτό:
   - εγκαθιστά την Python αν λείπει (μέσω winget)
   - αντιγράφει το πρόγραμμα στο **`C:\ITNow-Signage`**
   - φτιάχνει στην επιφάνεια εργασίας: **«ITNow Signage - Πίνακας Ελέγχου»** και **«ITNow Signage - Φάκελος Προσφορών»**
   - βάζει την προβολή να ξεκινά **αυτόματα** με το άνοιγμα των Windows

## Φάκελοι
```
C:\ITNow-Signage\
  Προσφορές Εβδομάδας\
     (δικοί σας υποφάκελοι, π.χ. «Γαλακτοκομικά»)   ← εικόνες / βίντεο
  Προσφορές Ημέρας\
     (δικοί σας υποφάκελοι)
```
- Κάθε **υποφάκελος = μία καμπάνια**. Τους φτιάχνετε με το **＋ Νέος φάκελος** στον Πίνακα Ελέγχου, με όποιο όνομα θέλετε.
- Σειρά προβολής: πρώτα όλες οι ενεργές **της εβδομάδας**, μετά **έξτρα** οι ενεργές **της ημέρας**, και ξανά από την αρχή.
- Τα αρχεία παίζουν αλφαβητικά (βάλτε `01_`, `02_`… για δική σας σειρά).
- Υποστηρίζονται: `jpg png gif webp bmp` και `mp4 webm` (προτείνεται MP4/H.264).
- Νέα/διαγραμμένα αρχεία εφαρμόζονται αυτόματα στον επόμενο κύκλο — χωρίς επανεκκίνηση.

## Χρήση — Πίνακας Ελέγχου
Ανοίγει από τη συντόμευση «ITNow Signage - Πίνακας Ελέγχου» σαν σύγχρονη εφαρμογή (ανοιχτό/σκούρο θέμα όπως τα Windows):
- **Έναρξη / Διακοπή προβολής** πάνω δεξιά, με ένδειξη αν παίζει τώρα.
- **Εβδομάδα με μια ματιά**: τι παίζει κάθε μέρα, με τη σημερινή να ξεχωρίζει.
- **Κάρτα για κάθε φάκελο** με μικρογραφίες των αρχείων, διακόπτη ενεργός/ανενεργός, **κουμπιά ημερών Δευ…Κυρ**,
  έτοιμες επιλογές (Όλες, Καθημερινές, Σαβ/κο, Δευ–Τετ, Πέμ–Κυρ) και προαιρετικά ημερομηνίες Από/Έως.
  Κλικ στις μικρογραφίες ανοίγει τον φάκελο για να ρίξετε εικόνες/βίντεο.
- **＋ Νέος φάκελος** σε κάθε ενότητα.
- Όλα **αποθηκεύονται αυτόματα** με το κλικ.

Κλείνοντας τον Πίνακα Ελέγχου η προβολή **συνεχίζει** κανονικά.

Πλήκτρα στην προβολή: `→` επόμενο, `Alt+F4` έξοδος.

Οι ρυθμίσεις αποθηκεύονται στο `schedule.json`. Ο server ακούει μόνο τοπικά (`127.0.0.1:8765`).
